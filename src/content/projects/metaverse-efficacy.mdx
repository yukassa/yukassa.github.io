## Overview

コロナ禍以降のリモートワーク課題に対し、次世代の解決策としてメタバース（VR）技術の業務適合性を検証しました。
本プロジェクトの特長は、主観的なアンケート評価だけでなく、 **脳波（EEG）や音声データなどの客観的指標（バイタルデータ）** を用いて、「コミュニケーション（会議）」と「個人作業」の 2 つの側面から効果を定量化した点にあります。

## My Role

発起人、脳波専門エンジニアを含む 3 名体制のプロジェクトにおいて、私は**実験計画の具体化とデータ分析基盤の実装**を主導しました。

- **実験計画の立案・詳細設計:** 発起人のコンセプトと脳波エンジニアの知見（指標選定）をもとに、統計的に妥当な比較手法（被験者内比較やデータ取得数）を設計し、実行可能な実験計画へ落とし込みました。
- **分析パイプラインの実装:** 脳波エンジニアが作成した測定スクリプトのプロトタイプをベースに、エラー処理やデータ整形機能を追加し、異種データを統合して分析できるパイプラインとして実運用化しました。
- **データ分析・考察:** 実装したパイプラインを用いてデータの集計・可視化を行い、チームでの議論を通じて結果の解釈と技術書（TechBook）への執筆を行いました。

## Experimental Design: Physics-Based Approach

### "Small Data" における分析アプローチ

社内実証実験のため被験者数は $ N=8 $ と限定的であり、一般的な統計的仮説検定を行うにはサンプルサイズが不足していました。また、単純な平均比較（被験者間比較）では、個人の体調や性格による「個人差ノイズ」が検証の妨げとなります。

そこで、物理実験の知見を活かし、**被験者内比較デザイン（Within-Subject Design）** を採用しました。同一被験者が「Web 会議 vs VR 会議」「物理ディスプレイ vs 仮想ディスプレイ」の全条件を体験し、その**変化量（差分）や分散**に着目して解析することで、小規模データながらも個人差を考慮した妥当性の高い定量評価を行いました。

### 検証シナリオと KPI

| シナリオ                  | 比較対象                           | 評価指標 (KPI)                                                                           |
| :------------------------ | :--------------------------------- | :--------------------------------------------------------------------------------------- |
| **1. コミュニケーション** | VR 会議 vs Web 会議 vs 対面        | **活性度:** 音声解析による発話文字数<br/>**一体感:** アンケートによる主観評価            |
| **2. 個人作業**           | 仮想ディスプレイ(VR) vs 物理モニタ | **集中度:** 脳波($\beta/\alpha$ 比)による客観計測<br/>**身体負荷:** SSQ (VR 酔い) スコア |

## Technical Implementation

### 異種データ処理パイプラインの構築

性質の異なる非構造化データを分析可能な形式（構造化データ）に変換するため、データソースごとに独立した前処理パイプラインを Python で構築しました。

1.  **脳波データ (Time-Series):**
    - モバイルアプリからクラウドへ転送された Raw データを取得。
    - `SciPy` を用いてバンドパスフィルタ(Band-pass filter)を適用し、瞬きや体動によるアーチファクト（ノイズ）を除去した上で、周波数解析により $\alpha$ 波・$\beta$ 波成分を抽出。
2.  **音声データ (Audio/Text):**
    - 会議録音データを **Google Cloud Speech-to-Text API** に投入。
    - タイムスタンプ付きのテキストデータから参加者ごとの **「発話文字数」** を集計し、コミュニケーションの活性度を定量化するロジックを実装。
3.  **統合分析 (Integration):**
    - 各パイプラインの出力をタイムスタンプで結合し、`Pandas` DataFrame として統合。条件ごとの分布（箱ひげ図）や平均値の比較を実施。

```python
# 信号処理パイプラインの一部（バンドパスフィルタ）
import numpy as np
from scipy.signal import butter, lfilter

def bandpass_filter(data, lowcut, highcut, fs, order=5):
    """
    Butterworthフィルタにより、特定の周波数帯域（集中度を示すβ波など）のみを抽出
    """
    nyq = 0.5 * fs
    low = lowcut / nyq
    high = highcut / nyq
    b, a = butter(order, [low, high], btype='band')
    y = lfilter(b, a, data)
    return y

```

## Results & Insights

分析の結果、以下の知見が得られ、技術書（TechBook）および社内イベント（Tech Day）にて発表を行いました。

- **集中環境としての VR**: 仮想ディスプレイ環境では、Web 会議や物理モニタ環境と比較して **高い集中度（$\beta/\alpha$ 比）** を示す傾向が確認されました。視覚的ノイズを遮断する没入効果が示唆されました。
- **コミュニケーションの活性化**: 音声解析の結果、VR 会議における発話量の推移などを可視化し、Web 会議と比較した際のコミュニケーション様式の違いをデータから読み取りました。
- **運用課題**: 一方で、SSQ スコアからは長時間の利用における「眼精疲労」や「VR 酔い」のリスクも確認され、導入には適切な休憩ルールの設計が必要であると提言しました。
