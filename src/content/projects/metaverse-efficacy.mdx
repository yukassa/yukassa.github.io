## Overview

コロナ禍以降、Zoom や Teams などの Web 会議ツールが普及しましたが、「雑談が生まれにくい」「相手の反応がわかりにくい」といった課題も浮き彫りになりました。
本プロジェクトでは、次世代のコミュニケーション基盤として期待される**「メタバース会議ツール」**が、従来の Web 会議と比較して、チームのコミュニケーションの質（発話量や集中度）にどのような影響を与えるかを定量的に検証しました。

単なるアンケート調査に留まらず、**脳波（EEG）センサー**や**音声データ**を用いたマルチモーダル分析を行い、投資判断のための客観的な指標を経営層へ提供しました。

## Experimental Design

### スモールデータにおける統計的有意性の担保

社内実証実験の制約上、被験者数（サンプルサイズ）は $N=8$ と非常に限られていました。
一般的な A/B テスト（被験者間比較）を行うと、個人の性格や体調によるノイズ（個人差）が効果量よりも大きくなり、有意差が出ないリスクがありました。

そこで、同一の被験者が「Web 会議」と「メタバース会議」の両方を体験し、その差分を評価する**被験者内比較デザイン（Within-Subject Design / 対応のある t 検定）**を採用しました。これにより、個人差ノイズを相殺し、小規模データでも統計的に信頼できる結論を導き出しました。

## Technical Implementation

### 1. マルチモーダル・データパイプライン

非構造化データ（脳波、音声、ログ）を統合して分析するためのパイプラインを Python で構築しました。

- **脳波データ (EEG):** Muse2 デバイスから OSC 通信で取得した RAW データを、GCP 上のサーバーへストリーミング保存。
- **音声データ:** 会議録音データから「発話の被り（Overlap）」や「沈黙時間」を抽出。
- **信号処理:** `SciPy` を用いて脳波データにバンドパスフィルタを適用し、α 波・β 波成分を抽出して「集中度」指標を算出。

### 2. 分析コード例 (Signal Processing)

脳波データから集中指標を算出する処理のイメージです。

```python
import numpy as np
from scipy.signal import butter, lfilter

def bandpass_filter(data, lowcut, highcut, fs, order=5):
    nyq = 0.5 * fs
    low = lowcut / nyq
    high = highcut / nyq
    b, a = butter(order, [low, high], btype='band')
    y = lfilter(b, a, data)
    return y

def calculate_concentration_index(eeg_data, fs=256):
    # β波 (13-30Hz) と α波 (8-12Hz) を抽出
    beta = bandpass_filter(eeg_data, 13, 30, fs)
    alpha = bandpass_filter(eeg_data, 8, 12, fs)

    # パワー（振幅の二乗）を計算
    beta_power = np.mean(beta ** 2)
    alpha_power = np.mean(alpha ** 2)

    # 集中度指標 = β波 / (α波 + β波) などを定義して算出
    concentration = beta_power / (alpha_power + beta_power)
    return concentration

```
