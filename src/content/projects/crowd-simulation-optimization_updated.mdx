## Overview

創発現象や群衆挙動への関心から個人開発している、リアルタイム人流シミュレータです。

エージェントは選択した大域経路探索に従って目的地へ向かい、局所回避によって他のエージェントや壁との衝突を避けながら移動します。ブラウザ上では人数・速度・移動方式などを変更できるほか、壁・誘導板や Spawn / Goal ゾーンを編集し、その場で人流の変化を確認できます。

さらに、描画を伴わないヘッドレスシミュレーションと **GA（遺伝的アルゴリズム）・SA（焼きなまし法）・NSGA-II** を組み合わせ、移動時間・速度・密度を評価しながらオブジェクト配置を探索する仕組みを実装しています。

## Motivation

創発現象やマルチエージェントシステムへの関心から、個々のエージェントの局所的な移動ルールや、壁・誘導板などの環境条件が集団全体の流れにどのような変化を生むかを観察できる環境を作ることから開発を始めました。

開発を進める中で、「人流を可視化する」だけでなく、**経路探索や局所回避方式を変えたときに挙動がどう変わるか**、さらに **環境側の条件を変えることで集団挙動を改善できるか** を比較・探索できるよう、アルゴリズム比較、ボトルネック分析、配置最適化の機能を追加しています。

## Architecture

```text
map_config.json ──読込──> Go engine
                             │
                ┌────────────┼─────────────┐
                │ WebSocket  │ HTTP API    │ SSE
                │ 状態配信   │ 評価・比較  │ 最適化進捗
                │ 編集操作   │ 最適化・保存│
                ▼            ▼             ▼
                    JavaScript / p5.js
                       + Chart.js
                       （Browser）
```

| レイヤー               | 技術                        | 主な役割                                                                                             |
| :--------------------- | :-------------------------- | :--------------------------------------------------------------------------------------------------- |
| **Simulation Engine**  | Go                          | HTTP サーバー、経路探索、物理演算、局所回避、ヘッドレス評価、GA・SA・NSGA-II、比較・ボトルネック分析 |
| **Visualization / UI** | JavaScript, p5.js, Chart.js | エージェント描画、マップ編集、パラメータ操作、最適化・比較結果の可視化                               |
| **Communication**      | WebSocket, HTTP API, SSE    | リアルタイム状態配信と編集操作、単発の評価・比較・最適化制御、最適化進捗の逐次配信                   |

シミュレーション・経路探索・配置最適化・アルゴリズム比較は Go 側で実行し、ブラウザ側は計算済みの状態や評価結果を受け取って描画・操作する構成です。マップはリポジトリに同梱した `map_config.json` を読み込みます。

## Technical Challenges & Solutions

### 1. 大域経路探索と局所回避の分離

人流の挙動を比較するためには、「目的地までどの経路を選ぶか」と「周囲の人や壁をどう避けるか」を独立に扱える必要があると考えました。

- **Pluggable Navigation**  
  大域経路探索と局所回避を別々の設定として実装しました。大域経路探索は **A*、Flow Field、Goal Vector / Boids、Theta*、JPS、Potential Field** の6方式、局所回避は **Force、ORCA / RVO2、Social Force Model** の3方式から選択できます。
- **Algorithm Comparison**  
  6 × 3 の全18通りをヘッドレスシミュレーションで一括評価し、結果をヒートマップ等で比較できるようにしました。
- **Path Recalculation**  
  壁の追加・削除・移動時には経路を再計算し、誘導板の影響で経路から大きく外れた場合も現在位置から再探索することで、動的な空間変更へ追従させています。

### 2. リアルタイムな観察と空間編集

シミュレーション結果を後から確認するだけでなく、条件や空間を変更した結果をその場で観察できることを重視しました。

- **Go + WebSocket**  
  Go が 50 ms 間隔（20 Hz）でシミュレーションを更新し、計算済みのエージェント座標を WebSocket でブラウザへ配信します。
- **Incremental Data Delivery**  
  毎 tick 変化するエージェント座標とは別に、オブジェクト・ゾーン・設定などの静的データは初回接続時と変更時だけ配信し、ブラウザ側へ送る情報を分けています。
- **Interactive Map Editing**  
  ブラウザから壁・誘導板や Spawn / Goal ゾーンを配置・移動・削除できます。連続した同種オブジェクトはグループとして移動でき、ロックしたオブジェクトは最適化対象から除外できます。モバイルではタッチ操作にも対応しています。

### 3. シミュレーションを評価関数として使う配置探索

オブジェクト配置の良し悪しを静的な距離だけで決めるのではなく、各候補について実際に人流シミュレーションを実行し、その結果を評価する方式にしました。

- **Headless Evaluation**  
  各配置候補を描画なしでシミュレーションし、`avg_goal_ticks`、`avg_speed`、`max_density`、`goal_reach_rate` を計測します。候補間の比較条件を揃えるため、評価時の疑似乱数シードを固定しています。
- **Multiple Optimization Strategies**  
  GA / SA では平均到達時間・平均速度・最大密度を重み付き Fitness として扱い、重みはブラウザから変更できます。NSGA-II では平均到達時間と最大密集度を多目的に扱い、Pareto 解集合を提示します。
- **Parallelization & Cache**  
  候補評価は CPU コア数を上限として並列化し、同一配置の評価結果をキャッシュすることで、重複するヘッドレス評価を抑えています。
- **Bottleneck-aware Initialization**  
  現在の配置から混雑しやすいセルを分析し、その結果を最適化の初期候補生成へ反映できるようにしています。

## Outcome

単一の群衆モデルを可視化するだけでなく、**経路探索・局所回避・環境条件を切り替えながら集団挙動を比較し、その結果をもとに配置条件まで探索できる検証環境**を構築しました。

また、リアルタイム表示と計算量の大きい評価・最適化処理を分け、WebSocket・HTTP API・SSE を用途に応じて使い分けることで、インタラクティブな観察と反復的なシミュレーション評価を同じブラウザ UI から扱えるようにしています。

## Current Status

現在はローカル環境で動作する個人開発プロトタイプで、公開デモ環境は未整備です。

壁・誘導板、Spawn / Goal ゾーンはブラウザ UI から編集できます。ゲートについてはシミュレーション・最適化ロジックには実装されていますが、現状のブラウザ UI には新規配置する操作導線がありません。
