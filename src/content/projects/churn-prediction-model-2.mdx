## Overview

会員制サービスの解約率改善（Churn Rate Reduction）に向けたデータ分析プロジェクトです。
単に「解約しそうなユーザー」を予測するだけでなく、**「なぜそのユーザーが解約に至るのか」**という要因を特定できなければ、有効な引き止め施策が打てないというビジネス課題がありました。
本プロジェクトでは、機械学習モデル（LightGBM）による高精度な予測と、XAI（説明可能な AI）技術を用いた要因分析を組み合わせ、マーケティングチームがアクション可能なリストを提供しました。

## My Role

**ML エンジニア兼データアナリスト**として、データ抽出からモデル構築、施策提案までを一貫して担当しました。

- **探索的データ分析 (EDA):** AWS Athena を用いた数億レコード規模のログ解析と仮説立案。
- **モデル構築:** LightGBM を用いた予測モデルの開発とハイパーパラメータチューニング。
- **実務適用:** SHAP 値を用いた解約要因の言語化と、ビジネスサイドへのレポーティング。

## Technical Challenges & Solutions

### 1. ビッグデータからの特徴量エンジニアリング

「解約」という結果に対し、ユーザーの行動ログ（アクセス頻度、機能利用、問い合わせ履歴など）は多岐にわたります。単に全てのデータを突っ込むだけではノイズになります。

- **Solution: Hypothesis-Driven Feature Engineering**
  物理学の研究プロセスと同様に、「特定の機能を使わなくなったユーザーは満足度が下がっているのではないか？」といった**仮説**を立て、それを裏付ける特徴量（例：特定機能の利用間隔の分散、直近 1 ヶ月の変化率など）を作成しました。これにより、モデルの精度と解釈性を向上させました。

### 2. 不均衡データ (Imbalanced Data) への対処

解約ユーザー（正例）は継続ユーザー（負例）に比べて圧倒的に少ないため、単純な Accuracy（正解率）は指標になりません。

- **Solution: Metric Design & Sampling**
  評価指標として **AUC (Area Under the Curve)** を採用し、解約の見逃しを防ぎつつ誤検知を制御しました。また、学習時には `scale_pos_weight` 等の重み付け調整を行い、不均衡データでも適切に解約リスクを学習できるよう調整しました。

### 3. 「ブラックボックス」の解消 (Explainable AI)

勾配ブースティング木（GBDT）は精度が高い反面、予測根拠がブラックボックスになりがちです。「このユーザーはスコア 80%です」と伝えても、マーケティング担当者は「どう説得すればいいの？」と困ってしまいます。

- **Solution: SHAP Values**
  **SHAP (SHapley Additive exPlanations)** を導入し、予測スコアに対する各特徴量の寄与度を算出しました。
  「A さんは料金への感度が高い」「B さんは利用頻度の低下が主因」といった**個別の解約理由**を可視化することで、クーポン配布や機能ガイド配信など、ターゲットに合わせた最適な施策実行を可能にしました。

## Analysis Flow

1.  **Data Extraction:** AWS Glue/Athena を用いてデータレイクから行動ログを集計。
2.  **Preprocessing:** Python (Pandas) による欠損値処理、カテゴリ変数エンコーディング。
3.  **Modeling:** **LightGBM** による学習。Cross-Validation（交差検証）による汎化性能の確認。
4.  **Interpretation:** **SHAP** ライブラリを用いたモデル解釈と、重要度ランキングの作成。

```python
# SHAPによる要因分析のイメージ
import shap
import lightgbm as lgb

# モデルの学習
model = lgb.train(params, train_set, valid_sets=[valid_set])

# 解約要因の算出 (SHAP値)
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X_test)

# ビジネスサイドへのアウトプット例:
# "ユーザーID: 001 の解約リスクスコアは 0.85。
#  主な要因は '直近ログイン間隔の増加 (+0.4)' と 'キャンペーン反応率の低下 (+0.2)' です。"
```

## Results & Impact

予測精度: 実運用に耐えうる AUC スコアを達成し、無作為なアプローチと比較して捕捉率（Recall）を大幅に向上。
ビジネス貢献: 「解約予備軍リスト」と「推奨アクション」をセットで提供するフローを確立。一律のメール配信ではなく、ユーザーの状態に合わせたパーソナライズドな解約抑止施策（リテンション・マーケティング）を実現しました。
