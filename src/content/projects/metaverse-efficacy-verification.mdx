## Overview

コロナ禍以降のリモートワーク課題に対し、次世代の解決策としてメタバース（VR）技術の業務適合性を検証しました。
本プロジェクトの特長は、主観的なアンケート評価だけでなく、**脳波（EEG）や音声データなどの客観的指標（バイタルデータ）** を用いて、「コミュニケーション（会議）」と「個人作業」の 2 つの側面から効果を定量化した点にあります。

## My Role

プロジェクトリーダー、および脳波計測のドメインエキスパートを含む 3 名体制のプロジェクトにおいて、私は**実験計画の具体化とデータ分析パイプラインの実装**を主導しました。

- **実験計画の立案 (Experimental Design):**
  物理学実験の知見を活かし、限られた被験者数でも個体差によるノイズを排除し、客観的な妥当性を担保できる比較手法（被験者内比較など）を設計し、実行可能な実験計画へ落とし込みました。
- **堅牢なデータ処理フローの実装:**
  ドメインエキスパートが提示した脳波計測のプロトタイプをベースに、エラー処理やデータ整形機能を追加し、実運用レベルへリファクタリング。 また、動画・脳波・アンケートという異なる形式のデータに対し、**分析可能な CSV へ変換する前処理パイプライン**をそれぞれ構築しました。特に非構造な動画データに関しては、GCP API 連携を含む多段階の変換処理を実装し、定量データ抽出の自動化を実現しました。
- **信号品質評価ロジックの実装:**
  簡易脳波計特有のノイズや信号欠損に対処するため、統計的な **ノイズフィルタリングロジック** を実装し、信頼性の高いデータのみを動的に抽出する分析基盤を構築しました。
- **データ分析・執筆:**
  実装したパイプラインを用いてデータの集計・可視化を行い、チームでの議論を通じて結果の解釈と技術書（TechBook）への執筆を行いました。

## Experimental Design: Physics-Based Approach

### "Small Data" における分析アプローチ

社内実証実験のため被験者数は $N=8$ と限定的であり、一般的な統計的手法では有意差の検出が困難な条件下でした。また、単純な平均比較（被験者間比較）では、個人の体調や性格による「個人差ノイズ」が検証の妨げとなります。

そこで、物理実験の知見を活かし、**被験者内比較デザイン（Within-Subject Design）** を採用しました。同一被験者が「VR 会議 vs Web 会議 vs 対面会議」「仮想ディスプレイ vs 物理ディスプレイ」の全条件を体験し、その**変化量（差分）や分散**に着目して解析することで、小規模データながらも個人差を相殺した妥当性の高い定量評価を行いました。

### 検証シナリオと KPI

実験では「コミュニケーション」と「個人作業」の 2 つのシナリオを設定し、それぞれのパフォーマンスと集中度を測定しました。また、VR 特有の身体的影響（VR 酔い）については、全シナリオ共通で SSQ アンケートによる詳細評価を行いました。

| シナリオ                              | 比較対象                             | 評価指標 (KPI)                                                                                                                                                               |
| :------------------------------------ | :----------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. コミュニケーション**<br />(会議) | VR 会議<br />Web 会議<br />対面      | **発言量:** 音声データ解析<br /><small>（会議での発言しやすさを評価）</small><br />**集中度:** 脳波 ($\beta/\alpha$ 比)<br /><small>（会議への没入・集中状態を評価）</small> |
| **2. 個人作業**<br />(タスク)         | 仮想ディスプレイ(VR)<br />物理モニタ | **タスク効率:** タスク完了時間<br /><small>（作業スピードを評価）</small><br />**集中度:** 脳波 ($\beta/\alpha$ 比)<br /><small>（作業への集中状態を評価）</small>           |

**▼ 安全性・身体負荷評価 (SSQ アンケート)**
VR 酔いの要因を特定するため、以下の 3 項目でスコアリングを行いました。

- **Nausea (吐き気):** 胃の不快感など
- **Oculomotor (眼球運動):** 目の疲れ、焦点調節の困難さなど
- **Disorientation (方向感覚の喪失):** めまい、くらくらする感覚など

## Technical Implementation

### ノイズ耐性のあるデータ処理パイプライン

簡易脳波計（Muse2）は装着ズレや体動によるノイズが入りやすいため、Python (`Pandas`, `NumPy`) を用いて **「信号の安定性」を動的に評価・選択するロジック** を構築しました。

1.  **動的チャンネル選択 (Dynamic Channel Selection):**
    前頭部の 2 チャンネル（AF7, AF8）において、常に両方の信号が綺麗に取れるとは限りません。そこで、各チャンネルの信号分布の **標準偏差 ($\sigma$)** を計算し、分布の広がりが小さい（＝外れ値やスパイクノイズが少なく安定している）チャンネルを自動的に分析対象として採用するアルゴリズムを実装しました。
2.  **外れ値の除去 (Outlier Rejection):**
    四分位範囲（IQR）を用いた統計的なフィルタリングを行い、突発的な体動ノイズを除去した上で、集中度指標（$\beta / \alpha$）を算出しました。

```python
# チャンネル選択ロジックの概念コード (Python)
import numpy as np

def select_best_channel(df):
    """
    AF7, AF8 のうち、標準偏差が小さく安定しているチャンネルを採用する
    """
    std_af7 = df['AF7'].std()
    std_af8 = df['AF8'].std()

    if std_af7 < std_af8:
        return df['AF7']  # AF7を採用
    else:
        return df['AF8']  # AF8を採用
```

## Results & Insights

分析の結果、以下の知見が得られ、技術書（TechBook）および社内イベント（Tech Day）にて発表を行いました。

- **集中環境としての VR:** 仮想ディスプレイ環境では、Web 会議や物理モニタ環境と比較して **高い集中度（$\beta/\alpha$ 比）** を示す傾向が確認されました。視覚的ノイズを遮断する没入効果が示唆されました。
- **眼球運動への負荷 (Oculomotor):** SSQ スコアの詳細分析により、VR 酔いの主因が「**眼球運動（Oculomotor）由来の眼精疲労**」にあることを特定。これに基づき、導入時には適切な休憩ルール（焦点距離の開放など）の設計が必要であると提言しました。
