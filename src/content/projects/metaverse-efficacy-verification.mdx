## Overview

コロナ禍以降のリモートワーク課題に対し、次世代の解決策としてメタバース（VR）技術の業務適合性を検証しました。
本プロジェクトの特長は、主観的なアンケート評価だけでなく、 **脳波（EEG）や音声データなどの客観的指標（バイタルデータ）** を用いて、「コミュニケーション（会議）」と「個人作業」の 2 つの側面から効果を定量化した点にあります。

## Experimental Design: Physics-Based Approach

### "Small Data" における分析アプローチ

社内実証実験のため被験者数は $ N=8 $ と限定的であり、一般的な統計的仮説検定を行うにはサンプルサイズが不足していました。また、単純な平均比較（被験者間比較）では、個人の体調や性格による「個人差ノイズ」が検証の妨げとなります。

そこで、物理実験の知見を活かし、**被験者内比較デザイン（Within-Subject Design）** を採用しました。同一被験者が「Web 会議 vs VR 会議」「物理ディスプレイ vs 仮想ディスプレイ」の全条件を体験し、その**変化量（差分）や分散**に着目して解析することで、小規模データながらも個人差を考慮した妥当性の高い定量評価を行いました。

### 検証シナリオと KPI

| シナリオ                  | 比較対象                           | 評価指標 (KPI)                                                                           |
| :------------------------ | :--------------------------------- | :--------------------------------------------------------------------------------------- |
| **1. コミュニケーション** | VR 会議 vs Web 会議 vs 対面        | **活性度:** 音声解析による発話文字数<br/>**一体感:** アンケートによる主観評価            |
| **2. 個人作業**           | 仮想ディスプレイ(VR) vs 物理モニタ | **集中度:** 脳波($\beta/\alpha$ 比)による客観計測<br/>**身体負荷:** SSQ (VR 酔い) スコア |

## Technical Implementation

### ノイズ耐性のあるデータ処理パイプライン

簡易脳波計（Muse2）は装着ズレや体動によるノイズが入りやすいため、Python (`Pandas`, `NumPy`) を用いて** 「信号の安定性」を動的に評価・選択するロジック**を構築しました。

1.  **動的チャンネル選択 (Dynamic Channel Selection):**
    前頭部の 2 チャンネル（AF7, AF8）において、常に両方の信号が綺麗に取れるとは限りません。そこで、各チャンネルの信号分布の**標準偏差 ($\sigma$)** を計算し、分布の広がりが小さい（＝外れ値やスパイクノイズが少なく安定している）チャンネルを自動的に分析対象として採用するアルゴリズムを実装しました。
2.  **外れ値の除去 (Outlier Rejection):**
    四分位範囲（IQR）を用いた統計的なフィルタリングを行い、突発的な体動ノイズを除去した上で、集中度指標（$\beta / \alpha$）を算出しました。
3.  **音声データの定量化:**
    会議録音データを **Google Cloud Speech-to-Text API** でテキスト化し、タイムスタンプに基づいて発話量（文字数）を集計・統合しました。

```python
# チャンネル選択ロジックの概念コード (Python)
import numpy as np

def select_best_channel(df):
    """
    AF7, AF8 のうち、標準偏差が小さく安定しているチャンネルを採用する
    """
    std_af7 = df['AF7'].std()
    std_af8 = df['AF8'].std()

    if std_af7 < std_af8:
        return df['AF7']  # AF7を採用
    else:
        return df['AF8']  # AF8を採用
```

## Results & Insights

分析の結果、以下の知見が得られ、技術書（TechBook）および社内イベント（Tech Day）にて発表を行いました。

- **集中環境としての VR**: 仮想ディスプレイ環境では、Web 会議や物理モニタ環境と比較して 高い集中度（$\beta/\alpha$ 比） を示す傾向が確認されました。視覚的ノイズを遮断する没入効果が示唆されました。
- **コミュニケーションの活性化**: 音声解析の結果、VR 会議における発話量の推移などを可視化し、Web 会議と比較した際のコミュニケーション様式の違いをデータから読み取りました。
- **眼球運動への負荷 (Oculomotor)**: SSQ スコアの詳細分析により、VR 酔いの主因が「吐き気」ではなく「**眼球運動（Oculomotor）由来の眼精疲労**」にあることを特定。これに基づき、導入時には適切な休憩ルール（焦点距離の開放など）の設計が必要であると提言しました。
