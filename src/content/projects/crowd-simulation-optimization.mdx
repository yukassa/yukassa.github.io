## Overview

物理学のバックグラウンドを活かし、群衆・複雑系のふるまいを数理モデルとして実装・可視化する個人研究プロジェクトです。
「避難行動のボトルネック分析」と「群れ行動のリアルタイムシミュレーション」という2つのテーマに取り組んでいます。

## Crowd Evacuation Simulation

建物内における群衆の避難行動を **Social Force Model（社会力モデル）** で実装しました。
個体間の反発力・壁からの作用力を数理モデル化し、出口付近で発生するボトルネック形成のメカニズムを可視化しています。

## Boid Simulation (Go/Ebiten)

鳥の群れや魚群のような複雑な動きを、シンプルな 3 つのルール（分離・整列・結合）のみで再現する **Boid (Bird-oid) アルゴリズム** の実装実験です。
バックエンド言語である **Go** の並行処理性能（Goroutines）を活かし、個体数が増えても 60FPS を維持できるかを検証しました。

単純な総当たり判定（$O(N^2)$）では個体数が増えると計算量が爆発するため、シミュレーション空間をグリッド（四分木）に分割し、近傍の個体とのみ相互作用を計算することで、計算量を $O(N \log N)$ 程度まで削減しています。

## Tech Stack

- **Language:** Python / Go
- **Library:** NumPy, Matplotlib, Ebiten (2D Game Engine)
- **Deployment:** WebAssembly（Boidシミュレーションはブラウザ上で動作）
